# Simple Dialogue Wiki

Simple Dialogue adds lightweight left/right NPC dialogue trees to Paper servers. It stores conversations as YAML files and integrates with FancyNpcs through the `simple_dialogue` action.

## Docs Strategy

Keep `README.md` as the fast install and quick-start page. Use the wiki for longer how-to material, server-owner workflows, troubleshooting, and release compatibility notes.
