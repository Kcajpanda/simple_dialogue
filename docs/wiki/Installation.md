# Installation

## Requirements

- Paper server compatible with this release
- Java 25 or newer
- FancyNpcs 2.10.0 or compatible newer version

Spigot is not supported.

## Install

1. Stop the server.
2. Install FancyNpcs.
3. Place the Simple Dialogue jar in `plugins/`.
4. Start the server.
5. Confirm `SimpleDialogue` appears in `/plugins`.
6. Confirm sample files were created in `plugins/SimpleDialogue/dialogues/`.

On startup, the console should log that the FancyNpcs action `simple_dialogue` was registered. If FancyNpcs is missing, use the console-command fallback from the Quick Start page.
